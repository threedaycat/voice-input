# 两种写法：
#   一行一个词              → 写进提示词，告诉模型"听到发音相近的，按这个写法输出"
#   错误写法 => 正确写法     → 转写完再逐条替换，模型还是写错时兜底（英文不分大小写，按整词匹配）
#
# 建议：先用几天，把真实转写里反复听错的词加进来。词表太长反而会让模型往词表里的词上靠。
